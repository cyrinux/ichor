Your Talos cluster, from your phone.

Ichor puts your Talos Linux cluster in your pocket. It talks to the Talos API with the official Go client, the same code as talosctl, so talosconfig contexts, mTLS and endpoint-to-node proxying behave exactly as they do on your workstation.

Bring your own cluster: the app needs a talosconfig for a Talos Linux cluster you run. It has no server and no account of its own.

<b>What you see</b>
• Cluster overview: every node ready, not ready or unreachable, with unmet conditions, clock drift and available Talos upgrades
• Services and logs: service health, service and kernel logs colored by level, repeats folded, live follow
• Events: service changes, boot phases and address changes as they happen
• Live graphs: CPU, memory, network, disk and load every two seconds, and the process list
• Pods: containers grouped by pod, with CPU and memory
• Network: interfaces, addresses, routes, DNS, time servers and open connections
• etcd: members, leader, size and alarms, defragmentation and snapshots
• KubeSpan: each node's peers, state, last handshake and traffic

<b>What you can do, with the right role</b>
• Start, stop or restart a service
• Reboot (graceful, power cycle or force) or shut down a node, after typing its hostname to confirm
• Capture packets live and save a .pcap for Wireshark
• Upgrade Talos one node at a time, refused if etcd would lose quorum
• Run the cluster health check, read and edit the machine config (tried with an automatic revert), open a debug shell
• Issue a talosconfig, renew this phone's certificate, export a kubeconfig

<b>Your phone gets only the access you give it</b>
Generate a dedicated talosconfig for the phone: os:reader is the recommended default. The app reads the certificate's roles and only offers what they allow. The config is encrypted with a key held in the Android Keystore and excluded from backups. Import it from a file, by pasting it, or by scanning a QR code.

<b>Always know which cluster you are on</b>
Import several clusters and swipe between them. Each one has its own color and the whole app takes it on, so a reboot never hits the wrong cluster.

<b>Alerts and widget</b>
Background checks notify you when a node goes down or the phone's certificate is about to expire, and a home-screen widget shows the cluster at a glance.

<b>Privacy and safety</b>
• Optional fingerprint or PIN lock, at launch and before every reboot, shutdown and kubeconfig export
• Screenshot mode replaces addresses and node names with stand-ins
• Lock-screen notifications stay generic while the app lock is on
• No ads, no tracking, no account

<b>Optional AI diagnosis</b>
Off by default, and hidden until you turn it on. It builds a report of the cluster state and shows it to you; only when you tap Ask is it sent to Anthropic (Claude), OpenAI or your own compatible server, with your own API key. Node names, addresses and the domain are anonymized by default. Without an API key, you can hand the report to an assistant app through the share sheet.
