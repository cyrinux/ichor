在手机上管理任意 Kubernetes 集群，并掌控整个 Talos 层。

Ichor 可通过 kubeconfig 打开任意 Kubernetes 集群：EKS、GKE、AKS、DigitalOcean、Rancher、Omni 或你自建的集群，支持 OIDC 和云平台登录。在 RBAC 允许的范围内查看工作负载、Pod、日志、事件、Argo CD 和 Flux。

在 Talos Linux 上，它可以深入到节点：节点健康状况、etcd、升级和机器配置。它使用官方 Go 客户端（与 talosctl 相同的代码）与 Talos API 通信，因此 talosconfig 上下文、mTLS 以及端点到节点的代理，行为与在你的工作站上完全一致。

自带集群：应用需要你所运行集群的 kubeconfig 或 talosconfig。它没有自己的服务器，也没有账号。

<b>你能看到什么</b>
• 集群概览：每个节点就绪、未就绪或无法访问，以及未满足的条件、时钟漂移和可用的 Talos 升级
• 服务与日志：服务健康状况，按级别着色的服务和内核日志，折叠重复行，实时跟随
• 事件：实时显示服务变化、启动阶段和地址变化
• 实时图表：每两秒刷新的 CPU、内存、网络、磁盘和负载，以及进程列表
• Pod：按 Pod 分组的容器，附带 CPU 和内存
• 网络：接口、地址、路由、DNS、时间服务器和已打开的连接
• etcd：成员、leader、大小和告警，碎片整理和快照
• KubeSpan：每个节点的对等节点、状态、最近握手和流量

<b>拥有相应角色时你能做什么</b>
• 启动、停止或重启服务
• 重启（正常、断电重启或强制）或关闭节点，需输入主机名确认
• 实时抓包并保存为 .pcap 供 Wireshark 使用
• 逐个节点升级 Talos，若 etcd 将失去法定人数则拒绝执行
• 运行集群健康检查，查看和编辑机器配置（试用模式，自动回退），打开调试 shell
• 签发 talosconfig，续期本机证书，导出 kubeconfig

<b>手机只拥有你授予它的权限</b>
为手机生成一个专用的 talosconfig：推荐默认使用 os:reader。应用会读取证书的角色，只提供角色允许的操作。配置使用存放在 Android Keystore 中的密钥加密，且不包含在备份中。可从文件导入、粘贴导入或扫描 QR 码导入。

<b>始终清楚自己在哪个集群</b>
导入多个集群并滑动切换。每个集群都有专属颜色，整个应用随之变色，重启操作绝不会误操作到错误的集群。

<b>告警与小组件</b>
后台检查会在节点宕机或本机证书即将过期时通知你，主屏幕小组件让你一眼掌握集群状态。

<b>隐私与安全</b>
• 可选的指纹或 PIN 锁，在启动时以及每次重启、关机和导出 kubeconfig 之前验证
• 截图模式会用替代值替换地址和节点名称
• 开启应用锁时，锁屏通知只显示通用内容
• 无广告、无跟踪、无账号

<b>可选的 AI 诊断</b>
默认关闭，开启前不会显示。它会生成一份集群状态报告并先展示给你；只有在你点按“提问”时，才会使用你自己的 API 密钥发送给 Anthropic（Claude）、OpenAI 或你自己的兼容服务器。默认情况下，节点名称、地址和域名会被匿名化。没有 API 密钥时，也可以通过分享菜单把报告交给助手类应用。
