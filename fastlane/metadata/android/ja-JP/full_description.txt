あらゆる Kubernetes クラスターをスマートフォンから。さらに Talos のレイヤー全体まで。

Ichor は kubeconfig からあらゆる Kubernetes クラスターを開きます。EKS、GKE、AKS、DigitalOcean、Rancher、Omni、または自前のクラスターに、OIDC やクラウドのサインインで接続できます。ワークロード、Pod、ログ、イベント、Argo CD、Flux を、RBAC が許す範囲で操作できます。

Talos Linux ではノードのレベルまで踏み込みます。ノードのヘルス、etcd、アップグレード、マシン構成。talosctl と同じ公式の Go クライアントで Talos API と通信するため、talosconfig のコンテキスト、mTLS、エンドポイントからノードへのプロキシは、作業用のマシンとまったく同じように動作します。

クラスターは各自でご用意ください：自分が運用するクラスターの kubeconfig または talosconfig が必要です。アプリ独自のサーバーやアカウントはありません。

<b>確認できること</b>
• クラスターの概要：各ノードの準備完了・未準備・到達不能の状態、満たされていない条件、時刻のずれ、利用可能な Talos のアップグレード
• サービスとログ：サービスのヘルス、レベルごとに色分けされたサービスとカーネルのログ、繰り返しの折りたたみ、ライブ追従
• イベント：サービスの変化、ブートフェーズ、アドレスの変化をリアルタイムで
• ライブグラフ：CPU、メモリ、ネットワーク、ディスク、負荷を2秒ごとに更新、プロセス一覧
• Pod：Pod ごとにまとめたコンテナと CPU・メモリ
• ネットワーク：インターフェース、アドレス、ルート、DNS、タイムサーバー、開いている接続
• etcd：メンバー、リーダー、サイズとアラーム、デフラグとスナップショット
• KubeSpan：各ノードのピア、状態、最後のハンドシェイク、トラフィック

<b>適切なロールでできること</b>
• サービスの起動、停止、再起動
• ホスト名を入力して確認したうえで、ノードを再起動（通常、電源再投入、強制）またはシャットダウン
• パケットをライブでキャプチャし、Wireshark 用の .pcap を保存
• Talos を1ノードずつアップグレード（etcd がクォーラムを失う場合は拒否）
• クラスターのヘルスチェックの実行、マシン構成の閲覧と編集（自動で元に戻る試行モード付き）、デバッグシェルを開く
• talosconfig の発行、このスマートフォンの証明書の更新、kubeconfig のエクスポート

<b>スマートフォンには与えた権限だけ</b>
スマートフォン専用の talosconfig を生成してください。推奨のデフォルトは os:reader です。アプリは証明書のロールを読み取り、許可された操作だけを提示します。構成は Android Keystore に保持された鍵で暗号化され、バックアップからは除外されます。ファイルから、貼り付けて、または QR コードをスキャンしてインポートできます。

<b>今どのクラスターにいるか、常にわかる</b>
複数のクラスターをインポートし、スワイプで切り替えられます。クラスターごとに色があり、アプリ全体がその色になるので、誤ったクラスターを再起動することはありません。

<b>アラートとウィジェット</b>
バックグラウンドチェックが、ノードのダウンやスマートフォンの証明書の期限切れが近いことを通知し、ホーム画面のウィジェットでクラスターの状態をひと目で確認できます。

<b>プライバシーと安全性</b>
• 起動時と、すべての再起動、シャットダウン、kubeconfig のエクスポートの前に、オプションの指紋認証または PIN ロック
• スクリーンショットモードでアドレスとノード名を代替の値に置き換え
• アプリロックがオンの間、ロック画面の通知は一般的な内容のみ
• 広告なし、トラッキングなし、アカウント不要

<b>オプションの AI 診断</b>
デフォルトではオフで、有効にするまで表示されません。クラスターの状態のレポートを作成して表示し、「質問する」をタップしたときにだけ、自分の API キーを使って Anthropic（Claude）、OpenAI、または互換性のある自前のサーバーに送信します。ノード名、アドレス、ドメインはデフォルトで匿名化されます。API キーがなくても、共有シートからアシスタントアプリにレポートを渡せます。
